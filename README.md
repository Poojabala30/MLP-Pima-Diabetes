# MLP Pima Diabetes Prediction

## About the Project

This project implements a Multilayer Perceptron (MLP) neural network
for predicting diabetes using the Pima Indians Diabetes Dataset.

## Objective

The objective of this project is to predict whether a person has
diabetes based on medical diagnostic measurements.

## Technologies Used

- Python
- PyTorch
- Pandas
- NumPy
- Scikit-learn

## Model

A Multilayer Perceptron (MLP) neural network is implemented using
PyTorch for binary classification.

## Dataset

Pima Indians Diabetes Dataset.

The dataset is loaded directly from a publicly available CSV source
in the Python program.

## Evaluation Metrics

The model is evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC

## Results

Accuracy: 69.48%

Precision: 0.5556

Recall: 0.6481

F1-Score: 0.5983

ROC-AUC: 0.7797
